## x.com or twitter.com: which URL to use

When Twitter rebranded to X in 2023, the domain moved from `twitter.com` to `x.com`. Both URLs still work. `twitter.com/yourhandle` redirects to `x.com/yourhandle`. For a QR code, use `x.com/yourhandle`. It is shorter and avoids the redirect, which makes for a slightly smaller QR pattern.

Either way, when someone scans the code, they land on your X profile.

## What this QR code actually does

When someone scans the code, their phone reads the encoded x.com URL. If they have the X app installed, the phone will usually prompt them to open the profile in the app. If not, the link opens in a browser.

This is a static QR code. It encodes your URL at the moment you generate it. If you change your X username later, the old QR code will no longer point to your profile. Generate a new one after any username change.

## A note about "Twitter barcode"

Some people search for a "Twitter barcode" or "X barcode generator" when they mean a QR code. QR codes are technically a type of 2D barcode, so the terminology gets mixed up. Traditional barcodes (the ones on product packaging) are one-dimensional and hold much less data. QR codes are two-dimensional and can store a full URL. If you searched for a Twitter or X barcode and landed here, this is the right tool.

## Static vs dynamic: what to know

This tool generates static QR codes. Your x.com URL is encoded directly into the pattern. If your X username changes, you need to generate a new QR code.

Dynamic QR codes from third-party paid services let you update the destination URL through a dashboard without reprinting the code. They also provide scan analytics.

For most uses, static is fine. If you need to know how many times the code gets scanned, run your X profile URL through a link shortener with analytics first, then encode that short link here.

## File format guide for printing

Use **SVG** for any printed material: business cards, conference handouts, posters. SVG is a vector format and stays crisp at any physical size.

Use **PNG at 512px or higher** for print if your design software does not support SVG. For digital use, 256px to 300px is enough.

Do not use JPEG. JPEG compression blurs the sharp edges of QR modules, which is the most common cause of a printed code that fails to scan.

## Frequently Asked Questions (FAQ)

### Should I use my x.com or twitter.com URL?

Use x.com. Both URLs work and will redirect to your X profile when scanned, but x.com is the current canonical domain. It is also shorter, which produces a slightly simpler QR pattern.

### My username contains underscores or numbers. Will that work?

Yes. The QR code encodes the full URL as-is, including any underscores, numbers, or other characters in your handle. Paste the full URL directly from your browser address bar and it will encode correctly.

### Will the QR code expire?

No. The QR code encodes a static URL with no expiry. It works as long as your X account exists at that username. If you change your username or delete your account, the link stops working because the URL it points to is no longer valid. The code itself has no time limit.

### Does the person scanning need the X app?

No. The QR code opens a standard x.com URL. Any phone camera can read it. If X is not installed, the link opens in a browser and loads your public profile page.

### Can I track how many people scan the QR code?

No. This tool generates a standard QR code with no tracking built in. If you need scan analytics, run your x.com URL through a link shortener with analytics first, then encode the shortened URL here.

### Can I create a QR code for an X business account?

Yes. Business accounts and personal accounts use the same URL format. Open the account profile in a browser, copy the URL, and paste it into the tool.

### What happened to the Twitter QR code that was in the app?

Twitter had a built-in profile QR code in the mobile app's profile settings. That feature was removed after the rebrand to X. The QR code you generate here is a direct replacement: a downloadable image file of your x.com URL that you can use in any printed or digital context.

### What file format should I use for a printed business card?

Use SVG. It is a vector format and stays sharp at any printed size. If your card design software does not support SVG, use PNG at 512px minimum. Do not use JPEG.
