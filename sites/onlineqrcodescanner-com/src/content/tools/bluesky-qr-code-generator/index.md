## What this QR code actually does

When someone scans the QR code, their phone reads the encoded bsky.app URL. If they have the Bluesky app installed, the phone will usually prompt them to open the profile in the app. If not, the link opens in a browser and loads your public Bluesky profile.

This is a static QR code. Your profile URL is encoded into it at the time you generate it. If you change your Bluesky handle later, the old QR code will stop working because the URL it encodes will no longer be valid. Generate a new one after any handle change.

## How to find your Bluesky profile URL

**Standard handle:** Log into bsky.app, click your profile picture or your name to go to your profile page, and copy the URL from the address bar. It looks like `https://bsky.app/profile/yourhandle.bsky.social`.

**Custom domain handle:** If you have set up a custom domain as your Bluesky handle (for example `yourdomain.com`), your profile URL looks like `https://bsky.app/profile/yourdomain.com`. Copy it the same way.

Either format works in this tool. Paste the full URL including `https://`.

## Static vs dynamic: what to know

This tool creates static QR codes. The bsky.app profile URL is encoded directly into the pattern. Once you print a static code, the URL it contains cannot be changed without printing a new one.

Dynamic QR codes from paid third-party services encode a redirect URL that you can update through a dashboard. They also provide scan analytics.

For most Bluesky users a static code is fine. Your handle is unlikely to change often, and most people do not need scan tracking. If you do want analytics, paste your Bluesky URL through a link shortener like Bitly first, then encode that short link here instead of the bsky.app URL directly.

## File format guide for printing

Use **SVG** for anything that will be printed. SVG is a vector format and stays perfectly sharp at any size, from a small business card to a large conference banner.

Use **PNG at 512px or higher** if your design software does not support SVG. For web use, 256px to 300px is enough.

Do not use JPEG. JPEG compression blurs the sharp edges of QR modules and is the most common reason a printed code fails to scan.

Test the code at the actual size you plan to print it at. A code that scans fine on screen may fail when printed very small because the individual modules become too small for a camera to resolve.

## Frequently Asked Questions (FAQ)

### Does my Bluesky handle need to end in .bsky.social?

No. If you use a custom domain as your Bluesky handle, your profile URL will look like `https://bsky.app/profile/yourdomain.com`. Paste that URL into the tool and it works the same way as a standard `.bsky.social` handle.

### Can I use my handle directly instead of the full URL?

Paste the full bsky.app profile URL for the most reliable result. That means including `https://bsky.app/profile/` before your handle. Some QR scanners will try to interpret a bare handle as text rather than a link, which breaks the tap-to-open behavior.

### Will the QR code expire?

No. The QR code encodes a static URL. It stays valid as long as your Bluesky handle does not change. If you change your handle, the URL it encodes will no longer point to your profile. Generate a new one after any handle change.

### Does the person scanning need the Bluesky app?

No. The QR code opens a bsky.app URL. Any phone camera can read it, and if Bluesky is not installed, the link opens in a browser and loads your public profile page.

### Can I track how many people scan the QR code?

No. This tool generates a standard QR code with no tracking built in. If you need scan analytics, run your bsky.app profile URL through a link shortener with analytics first, then encode that shortened URL here.

### What size should I use for a printed business card?

Use SVG for the most reliable result. If your printer or design software needs a raster file, use PNG at 512px minimum. For very small print sizes, test the code at actual print size before ordering a print run.
