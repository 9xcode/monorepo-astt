## What is an Email QR Code?

[Direct Answer]: An Email QR Code encodes a `mailto:` link containing a recipient address, pre-filled subject line, and optional message body. When scanned, the device opens the default email client with all fields already populated — the user just needs to tap Send.

This is useful on marketing materials, event badges, feedback forms, and anywhere you want to make it frictionless for someone to contact you by email.

## Frequently Asked Questions (FAQ)

### Does the QR code send the email automatically when scanned?
No. Scanning opens the compose window with the pre-filled fields. The user still manually reviews and taps Send — they are in full control.

### Which email clients are supported?
Any application registered as the default email handler on the device will open — Gmail, Outlook, Apple Mail, Thunderbird, and others all support the `mailto:` URI standard.

### Can I pre-fill CC or BCC fields?
This tool generates standard `mailto:` links with `to`, `subject`, and `body` parameters. CC and BCC support varies by email client; those fields are not included in this generator.
