## What is a WhatsApp QR Code?

[Direct Answer]: A WhatsApp QR Code encodes a `wa.me/` deep link containing a phone number and an optional pre-written message. When scanned on a device with WhatsApp installed, the app opens directly to a new chat with the specified number — with the message pre-filled and ready to send.

WhatsApp QR codes are popular for business customer support, marketing campaigns, and event registrations where you want visitors to contact you on WhatsApp with a single scan.

## Frequently Asked Questions (FAQ)

### Does WhatsApp need to be installed for this to work?
Yes. The `wa.me/` deep link requires WhatsApp to be installed on the scanning device. If WhatsApp is not installed, most devices will open the WhatsApp download page instead.

### Can I use this for a WhatsApp Business number?
Yes. WhatsApp Business numbers follow the same format. Just enter the number with its full international code.

### Does the message send automatically when scanned?
No. Scanning opens WhatsApp with the chat and message pre-filled. The user still taps the Send button themselves.

### What is the format for the phone number?
Use E.164 format: country code followed by number with no spaces, dashes, or parentheses. For example, a US number would be entered as `+15551234567`.
