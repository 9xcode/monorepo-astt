## What is a Text QR Code?

[Direct Answer]: A Text QR Code encodes arbitrary plain text — such as a message, note, coupon code, or any alphanumeric string — directly into the QR pattern. When scanned, the decoded text is displayed to the user without opening any browser or application.

Text QR codes are ideal for offline scenarios: sharing a short message at an event, encoding a discount code on a flyer, or storing any information that doesn't need a URL or app.

## Frequently Asked Questions (FAQ)

### How much text can a QR code hold?
A QR code can hold up to approximately 4,296 alphanumeric characters. The more text you encode, the denser the QR pattern, which requires a larger print size to scan reliably.

### Can a text QR code contain emojis?
Yes, but emoji characters increase the data density significantly. For best scan reliability, keep text concise and use standard ASCII characters when possible.

### What happens when someone scans a text QR code?
The scanner (phone camera or app) displays the decoded plain text directly. No browser is opened and no app is launched — it's just raw text shown on screen.
