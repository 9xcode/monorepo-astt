A Pinterest QR code encodes a Pinterest URL into a scannable image. Scan it and the link opens directly in a browser or the Pinterest app. This works for any Pinterest URL: a profile page, a specific board, or an individual pin.

This tool takes the Pinterest URL you paste in, converts it into a QR code image, and lets you download it as PNG, WEBP, or SVG.

## Profiles, boards, and pins: what you can link to

Unlike most social platforms where you only link to a profile, Pinterest gives you more options.

**Profile:** Links to everything you have saved and created. `https://www.pinterest.com/yourusername/`

**Board:** Links to a specific collection of pins. `https://www.pinterest.com/yourusername/boardname/`

**Individual pin:** Links to a single saved idea. The URL looks like `https://www.pinterest.com/pin/123456789/`

Which one you encode depends on what you want the person scanning to see. A food brand might link to a recipe board rather than the whole profile. A wedding venue might link to a specific inspiration board for upcoming couples.

## What this Pinterest QR code actually does

When someone scans the QR code, their phone reads the encoded Pinterest URL. If they have the Pinterest app installed, the phone will usually prompt them to open it there. If not, the link opens in a browser and loads the Pinterest page.

This is a static QR code. The URL is encoded at the time you generate it. If the Pinterest URL changes (you rename a board, delete the pin, change your username) the QR code will stop working. Generate a new one if anything changes.

## How to find your Pinterest URL

**Profile URL:** Open Pinterest in a browser. Click your profile picture or name in the top right to go to your profile. Copy the URL from the address bar. It looks like `https://www.pinterest.com/yourusername/`.

**Board URL:** Open the board you want to link to. The URL in the address bar includes your username and the board name, like `https://www.pinterest.com/yourusername/boardname/`.

**Pin URL:** Open the pin. The URL includes a unique numeric ID, like `https://www.pinterest.com/pin/123456789/`. Copy it directly from the address bar.

Paste whichever URL you need into the tool.

## A note about Pinterest Lens

Pinterest has a built-in camera scanner called Pinterest Lens. It is used to search Pinterest by pointing your camera at real-world objects, food, or products, not to scan QR codes. It is a visual search tool, not a QR code reader.

The QR code you create here is a standard QR code, not something specific to Pinterest. Any phone camera app can scan it. It is not related to Pinterest Lens.

## A note about "Pinterest barcode"

Some people search for a "Pinterest barcode generator" or "barcode pinterest" when they mean a QR code. QR codes are a type of 2D barcode. Traditional barcodes (the striped ones on retail products) are one-dimensional and store far less data. QR codes store full URLs. If you found this page searching for a Pinterest barcode, this is the right tool.

## Static vs dynamic: what to know

This tool generates static QR codes. The Pinterest URL is encoded directly into the pattern. Once you print a static code, the destination cannot be updated without reprinting.

For most uses this is fine. Pinterest profile URLs and board URLs are stable unless you rename things. If you need the ability to change the destination later without reprinting (for example, on packaging with a long print run), use a link shortener with redirect capability, encode that short link here, and update the destination through the shortener if needed.

## File format guide for printing

Use **SVG** for anything going to print: product packaging, business cards, brochures, event materials. SVG is a vector format and stays sharp at any size.

Use **PNG at 512px or higher** if your print setup does not support SVG. For digital use, 256px to 300px is fine.

Do not use JPEG. JPEG compression softens the edges of QR modules, which is the most common reason a printed code fails to scan.

Test the code at the actual size you plan to print it before committing to a full run.

## Frequently Asked Questions (FAQ)

### Can I create a QR code for a specific Pinterest board instead of my whole profile?

Yes. Open the board in a browser, copy the URL from the address bar, and paste it here. The QR code will link directly to that board. This is useful when you want to point people to a specific collection rather than your entire profile.

### Can I create a QR code for a single Pinterest pin?

Yes. Open the pin in a browser, copy the URL, and paste it here. Pin URLs contain a unique numeric ID and look like `https://www.pinterest.com/pin/123456789/`. The QR code will open that specific pin.

### Will the QR code work if the board is secret or the profile is private?

If the board or profile is set to private or secret on Pinterest, the QR code will still open the URL, but the person scanning will see a login screen or a message that the content is private. Make sure the page you are linking to is public before printing and distributing a QR code for it.

### Will the QR code expire?

No. The QR code encodes a static URL. It stays valid as long as the Pinterest URL it points to exists. If you rename a board, delete a pin, or change your username, the URL changes and the existing QR code will no longer work. Generate a new one after any changes that affect the URL.

### Can I track how many people scan the QR code?

No. This tool generates a standard QR code with no analytics. If you need scan tracking, run the Pinterest URL through a link shortener with analytics first, then encode the short link here instead of the direct Pinterest URL.

### What file format should I use for product packaging?

Use SVG. It scales to any size without quality loss, which matters for packaging where the QR code might need to print at a very specific size. If the packaging designer's software does not support SVG, use PNG at 512px minimum and verify the code scans at the actual print size before going to production.

### Does the person scanning need the Pinterest app?

No. The QR code opens a standard Pinterest URL. Any phone camera can read it. If Pinterest is not installed, the link opens in a browser and loads the page.

### My Pinterest URL has a long path with lots of slashes. Is that normal?

Yes. Board and profile URLs on Pinterest include your username and board name separated by slashes. That is the normal format and encodes into a QR code without any issues. Paste the full URL exactly as it appears in your browser address bar.
