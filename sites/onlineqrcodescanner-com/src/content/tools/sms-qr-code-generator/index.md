## What is an SMS QR Code?

[Direct Answer]: An SMS QR Code encodes an `sms:` URI containing a recipient phone number and an optional pre-written message body. When scanned, the device opens the native Messages app with the number and message already filled in — the user just taps Send.

SMS QR codes are useful for marketing campaigns, customer support flows, appointment confirmations, and any scenario where you want to lower the barrier for someone to send you a text message.

## Frequently Asked Questions (FAQ)

### Does the message send automatically when scanned?
No. Scanning opens the Messages app with the number and body pre-filled. The user reviews the message and manually taps Send.

### Is there a character limit for the pre-filled message?
The `sms:` URI standard does not impose a strict limit, but long messages may be truncated by some messaging apps. Keep pre-filled messages concise — ideally under 160 characters for a single SMS segment.

### What is the difference between an SMS QR code and a WhatsApp QR code?
An SMS QR code uses the native SMS/Messages app and works without internet connectivity. A WhatsApp QR code uses the `wa.me` deep link, which requires the WhatsApp app to be installed and an internet connection.
