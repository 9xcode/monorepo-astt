This tool generates a QR code that links to your Snapchat profile using the `snapchat.com/add/yourusername` URL. When someone scans it on a phone with Snapchat installed, the app opens a prompt to add you as a friend. On a phone without Snapchat, the link opens in a browser and shows your public profile.

This is different from a Snapcode (Snapchat's own yellow ghost logo QR). A Snapcode is generated by Snapchat inside the app and only scans with the Snapchat camera. The QR code you create here works with any phone camera and links to the same add-friend page.

## What `snapchat.com/add/` actually does

The URL this tool encodes (`https://snapchat.com/add/yourusername`) is Snapchat's official friend-add link. When someone scans the QR code:

- If Snapchat is installed, the app opens directly to your profile with an "Add Friend" button.
- If Snapchat is not installed, a browser opens showing your public profile page at `snapchat.com/add/yourusername`.

The person still has to tap "Add" themselves. Nothing is sent automatically.

## Snapcode vs this QR code

Snapchat's native Snapcode (the yellow ghost design) is generated by the app and is only scannable using Snapchat's built-in camera. It cannot be scanned with a standard phone camera or a third-party QR scanner.

The QR code this tool generates works with any camera app and any QR scanner. It links to the same `snapchat.com/add/` URL, so the outcome when scanned on a phone with Snapchat is identical. The difference is compatibility: Snapcodes require Snapchat to scan; these QR codes do not.

If you are putting a code somewhere where you know your audience uses Snapchat (like merchandise for Snapchat fans), a Snapcode from the app is fine. If you are printing on general materials where people might scan with their default camera app, use the QR code from this tool.

## Frequently Asked Questions

### What URL does this tool encode?

It encodes `https://snapchat.com/add/yourusername`. This is Snapchat's official friend-add link. When someone opens it on a phone with Snapchat installed, the app opens with your profile and an "Add Friend" button.

### Is this the same as a Snapcode?

No. A Snapcode is the yellow ghost logo QR that Snapchat generates inside the app. It only works with Snapchat's camera. The QR code from this tool works with any camera app. Both link to the same Snapchat profile; the difference is which cameras can read them.

### Does someone need Snapchat installed to use this QR code?

If they have Snapchat, the phone opens your profile in the app. If not, the `snapchat.com/add/` link opens in a browser showing your public profile. They would need the app to actually add you.

### Will the QR code expire?

No. It encodes a static URL. As long as your Snapchat username stays the same, the code stays valid. If you change your username, generate a new one.

### Can I track how many people scan it?

No. This tool generates a standard QR code with no analytics. If you need scan tracking, encode a short link (like a Bitly URL redirecting to your Snapchat add link) instead of the direct Snapchat URL.

### What file format for printing?

SVG for anything printed. It scales to any size without quality loss. If SVG is not supported, use PNG at 512px or higher. Do not use JPEG for QR codes. JPEG compression blurs the pattern edges, which causes scanning failures.
