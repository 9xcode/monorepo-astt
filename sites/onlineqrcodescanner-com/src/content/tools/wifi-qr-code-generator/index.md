## What is a Wi-Fi QR Code?

[Direct Answer]: A Wi-Fi QR Code encodes your wireless network credentials (SSID, password, and security type) in a standard format so that when someone scans it with their smartphone, they are prompted to join the network automatically — no manual password entry required.

This is the QR code you see displayed at cafés, hotels, offices, and events. It provides a fast and secure way to share network access without revealing your password visibly in text.

## Frequently Asked Questions (FAQ)

### Is my Wi-Fi password safe when I generate this QR code?
Yes. All encoding happens entirely inside your browser. Your network password is never sent to our servers or any third party.

### Which security type should I select?
Choose **WPA/WPA2** for virtually all modern routers. Select WEP only for legacy hardware, and None for truly open (password-free) networks.

### Does it work on iPhones?
Yes. iOS 11 and later natively recognizes Wi-Fi QR codes when scanned with the default Camera app and will prompt you to join the network automatically.

### Should I hide the QR code in a public place?
If your network is shared intentionally (café, office), displaying it is fine. For your personal home network, share it only with trusted guests. The QR code itself contains your password in encoded form.
