# @mtools Monorepo

A scalable pnpm monorepo for building multiple niche tool sites on a shared core — all powered by Astro, Svelte 5, and Tailwind CSS v4.

## Structure

```
monorepo-astt/
├── core/                     # @mtools/core — shared package
│   ├── src/
│   │   ├── components/       # All shared UI components (Astro + Svelte)
│   │   ├── layouts/          # BaseLayout, ToolLayout, BlogLayout
│   │   ├── pages/            # All shared route entrypoints (injected via core-pages)
│   │   ├── utils/            # Data utilities (blog, tools, authors, search…)
│   │   ├── seo/              # Schema.org builders (JSON-LD)
│   │   ├── config/           # SiteConfig types, factory, Astro config factory
│   │   ├── content-schemas/  # Zod schema factories for Astro content collections
│   │   ├── middleware/       # config-injector (populates Astro.locals.siteConfig)
│   │   ├── og/templates/     # OG image template functions
│   │   ├── styles/           # global.css, common.css, themes/
│   │   └── lib/              # shadcn-svelte components, Lucide icons, utils
│   ├── integrations/
│   │   ├── core-pages.ts     # Astro integration: middleware + injectRoute + aliases
│   │   ├── og-cache/         # OG image generation integration
│   │   └── widget-map/       # Widget map generation integration
│   └── scripts/
│       └── nuke.sh           # Total cleanup script (nuke node_modules, cache, dist)
│
├── sites/
│   ├── finance-tools/        # @mtools/finance-tools — MultiTools production site
│   │   ├── src/
```

## Quick Start

```bash
# Install all workspace dependencies
pnpm install

# Dev a specific site
pnpm --filter @mtools/finance-tools dev

# Build a specific site
pnpm --filter @mtools/finance-tools build

# Build all sites (Turborepo — only rebuilds what changed)
turbo build
```

## How It Works

### Site Configuration
Each site has a `src/config.ts` that calls `createSiteConfig()` from `@mtools/core/config/factory`. This resolves `buildTime` and `copyrightYear` automatically from the build environment.

### Virtual Config Module
All components access `siteConfig` via `import { siteConfig } from 'virtual:site-config'`. This virtual Vite module is registered by `createAstroConfig()` at build time — zero runtime overhead, no prop drilling.

### Shared Pages via `injectRoute()`
The `core-pages` Astro integration injects all 23 shared routes from `core/src/pages/` into every site. Sites can override any route by adding a file at the same pattern in their own `src/pages/`.

### Widget Code Splitting
The `@mtools/widget-map` Astro integration runs automatically during every dev/build. It scans `src/features/` and `src/content/tools/` to generate `src/generated/widgets/<slug>.astro` — one file per tool, one import each. Vite/Rollup code-splits them automatically so each tool page only downloads its own JS. In dev mode, it watches for new tool/widget additions and regenerates on the fly.

### Adding a New Site
See [docs/project/creating-new-site.md](docs/project/creating-new-site.md).

## Activating CI/CD

The GitHub Actions pipeline is written but inactive:
```bash
mv .github/workflows-disabled/ci.yml .github/workflows/ci.yml
```
See the file header for deployment provider setup (Vercel / Netlify / Cloudflare Pages).

## Tech Stack

| Layer | Technology |
|---|---|
| Framework | Astro v6 |
| UI Components | Svelte v5 (Runes) |
| Styling | Tailwind CSS v4 |
| UI Primitives | shadcn-svelte (bits-ui) |
| Icons | Lucide Svelte |
| Package Manager | pnpm workspaces |
| Build Orchestration | Turborepo |
| Content | Astro Content Collections |
| Schema Validation | Zod |
| OG Images | Satori + sharp |
| SEO | JSON-LD (Schema.org) |
